# Noodle – Web Presentation of a Chinese Restaurant

## Overview
**Noodle** is an interactive web presentation of a Chinese restaurant, built using **HTML, CSS, JavaScript**, and **Bootstrap**. The website aims to enhance customer engagement, attract more visitors, and simplify operations for restaurant staff.

Visitors can:  
- Browse and search the menu, which is divided into **Appetizers, Main Dishes, and Desserts**.  
- View detailed dish information including **name, description, price (small/large), image and average rating**.  
- Add dishes to a shopping cart, adjust quantities and finalize orders.  
- Switch between **Serbian and English** languages seamlessly.  
- Access responsive design optimized for **desktop, tablet, and mobile devices**.  
- Explore image and video galleries, see restaurant location on a functional map and contact the restaurant directly.  

The project emphasizes **professional web design**, including a consistent visual identity, intuitive navigation and breadcrumbs.

---

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript, Bootstrap   
- **Browser Support**: Chrome, Edge, Firefox, Safari  
- **Storage**: LocalStorage / SessionStorage for cart functionality  

---

## Project Highlights
- Uniform visual identity with header, footer and responsive layout.  
- Interactive menu with sorting and search functionality.  
- Multi-level navigation with horizontal and vertical menus.  
- Cart system with session persistence and downloadable PDF menu.  
- Multi-language support for Serbian and English.  
- Fully responsive for desktop, tablet, and mobile devices.
